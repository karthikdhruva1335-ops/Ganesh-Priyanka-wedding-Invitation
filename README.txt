PUBLISH FREE WITH GITHUB PAGES
1. Sign in at https://github.com
2. Click +, then New repository.
3. Name it ganesh-priyanka-wedding and make it Public. Create the repository.
4. Click Add file > Upload files, then upload index.html (and music.mp3 / images if used).
5. Click Commit changes.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
8. Wait for publishing and open the website link shown in Settings > Pages.
